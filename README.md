# 交互式任务清单 (Todo App)

云南大学 软件开发综合实践 课堂作业五 案例复现项目。

## 项目简介
本项目基于原生 HTML、CSS 和 JavaScript 构建，遵循“数据驱动视图（修改数组状态 → save() 持久化 → render() 统一渲染）”的设计模型，实现了一款轻量且体验良好的任务清单应用。

## 核心功能
1. **任务添加与表单校验**：监听 submit 事件并拦截默认表单跳转 (`e.preventDefault()`)，对输入内容去空格判空并给出友好提示；
2. **状态切换与标记完成**：点击任务文本即可实时切换完成状态，添加删除线样式；
3. **任务删除与事件冒泡拦截**：提供删除按钮，通过 `e.stopPropagation()` 阻止事件向上冒泡，安全移除特定任务；
4. **多状态过滤**：提供“全部”、“未完成”、“已完成”三态过滤功能；
5. **localStorage 本地持久化**：使用 `JSON.stringify` 与 `JSON.parse` 成对存取状态数组，页面刷新后数据完整保留。

## 技术栈
- HTML5
- CSS3
- 原生 JavaScript (DOM 操作、事件监听、localStorage)
